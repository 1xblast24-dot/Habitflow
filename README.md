# HabitFlow

Build habits. Build yourself.

A habit tracker with a landing page, sign-in, and a planner app. Accounts and habits are stored in Supabase, so your data follows you to any device.

## Pages
- `index.html`: landing page
- `login.html`: sign in / create account / continue as guest
- `app.html`: the habit tracker

## Run it
It is a static site. Turn on GitHub Pages (Settings, Pages, branch `main`) and open the site.
